# Prasad Temkar — Frontend Developer Portfolio

A responsive, performance-optimised portfolio built with React 18 and Vite 8,
showcasing five production projects: ShopKart, BiteBox, BiteBox V2, ChaloChale,
and the DEMS Evidence System.

## Tech Stack

- React 18
- Vite 8 (Rolldown)
- Vanilla CSS with custom properties (light/dark theme via `[data-theme]`)
- Native `loading="lazy"` for images
- `React.lazy` + `Suspense` for component-level code splitting
